# Coffee Globe

A mobile-first web app: a satellite globe of specialty roasters that ship to you, with palate matching built in. Pins glow by how well each roaster's coffees match your taste.

## Core loop (the MVP is done when this works end to end)
1. Open the app and see a globe of roasters that ship to your country (default: Canada).
2. Take a 60-second taste quiz (7 questions).
3. Roaster pins glow and grow by best match score.
4. Tap a pin to see that roaster's top 3 coffees for you.
5. Click through to buy on the roaster's own site.

Success signal: quiz completion and click-through to roaster sites.

## Scope
In: ~100 roasters (Canada first, plus US roasters that ship to Canada), ~1,000 coffees scraped from Shopify `/products.json`, taste quiz, globe with roaster and origin pins, origin-to-roaster arcs, "ships to me" filter, ranked list view, thumbs up/down to refine the profile.

Out (for now): accounts (profile lives in localStorage), checkout, reviews, brew logging, roaster portal, native apps, Supabase (data is static JSON in `data/` until the catalogue outgrows it).

## Taste model
Five axes, each 0–1: `acidity`, `sweetness`, `body`, `fruitiness`, `roast` (0 = very light, 1 = very dark).
- A coffee is a point in that space, produced by LLM extraction from the roaster's description and tasting notes.
- A user profile is a point plus a per-axis weight (how much they care).
- Match % = 100 × (1 − weighted Euclidean distance / max distance).
- Thumbs up pulls the profile 20% toward that coffee; thumbs down pushes it 10% away.
All of this lives in `lib/taste.ts` and is covered by `tests/taste.test.ts`.

## Layout
- `app/` – Next.js App Router pages
- `components/` – `GlobeView` (react-globe.gl, client-only), `Quiz`, `RoasterSheet`, `MatchList`
- `lib/` – types, taste model, data loading
- `data/` – `roasters.json`, `coffees.json`, `origins.json` (generated by the pipeline; the checked-in copy is fictional sample data)
- `pipeline/` – Python: `scrape.py` (Shopify), `extract.py` (Claude extraction), `build_data.py` (writes `data/`)

## Commands
- `npm run dev` – local dev server
- `npm test` – taste model tests
- `npm run build` – production build
- `cd pipeline && python -m pytest` – pipeline tests (no network)
- `python pipeline/scrape.py` → `python pipeline/extract.py` → `python pipeline/build_data.py`

## Rules
- Extraction quality is the product. After any change to `extract.py`'s prompt, spot-check at least 20 coffees by hand.
- Never invent coffees for real roasters. Sample data uses fictional roasters only.
- Respect roasters' sites: one request per second, identify the scraper with a plain User-Agent, and skip any site whose robots.txt disallows `/products.json`.
- Keep the globe fast on a phone: no more than ~200 points, no per-frame React state.
